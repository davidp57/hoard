# Shared libraries libmpv needs that SteamOS does NOT ship.
#
# Measured on a Steam Deck (SteamOS BUILD_ID 20260716.1, glibc 2.41) by
# comparing libmpv's dependency closure against `ldconfig -p`. Of the 178
# libraries in that closure, 118 are already on SteamOS — bundling those is
# what broke the first attempt: the system's libgio-2.0 required MOUNT_2_40
# from a libmount we had shipped from Ubuntu, which does not provide it, and
# nothing started at all.
#
# So this is a whitelist, not a blacklist. A blacklist has to name every
# transitive dependency of everything excluded, and missing one is silent.
#
# Regenerate on the target (with /tmp/sys.txt from `ldconfig -p | awk '{print $1}' | sort -u`):
#   for f in <bundle>/lib/*.so*; do b=$(basename "$f"); \
#     grep -qxF "$b" /tmp/sys.txt || echo "$b"; done | sort
