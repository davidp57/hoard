# BL-139 — Convention manette commune avec PadView

Status: 🔄 in-progress

## Quoi

[`docs/pad-convention.en.md`](../../../docs/pad-convention.en.md), miroir anglais de `docs/convention-manette.md` de PadView : une fonction, un endroit, dans les deux applications.

Côté Hoard, la convention ne demande rien de plus que BL-138 : Hoard en est la référence (Select = menu, Start = aide, R2 maintenu = couche de vue, toasts centrés, vibration, badge du modificateur).
Côté PadView (lot PV-35), elle a amené le menu Select, le cadrage sur R2, la vitesse et les sauts sur ThisVid, la vibration, le badge, l'aide qui défile, les noms de boutons et l'échelle d'interface.

## Règle

Toute modification de la convention se reporte dans les deux dépôts, dans le même mouvement.
